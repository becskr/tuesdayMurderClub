# Tuesday Murder Club: ready-to-run build

This branch is generated by GitHub Actions (`.github/workflows/krystal-build.yml`) every time the source branch is pushed. Don't edit it by hand: changes will be overwritten.

- `server.js` is the startup file for cPanel's Setup Node.js App.
- `app/` is the Next.js standalone build, including the packages it needs.
- `BUILD_COMMIT` is the source commit this was built from.

To update the live site: cPanel → Git Version Control → Pull or Deploy → Update from Remote, then Setup Node.js App → Restart.
